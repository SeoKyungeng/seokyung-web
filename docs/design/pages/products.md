# 가공제품 페이지 구성

> 비주얼 중심 — 풀블리드 갤러리, 마소닉 그리드, 라이트박스

---

## 레이아웃

### Section 1 — 페이지 헤더 (70vh)

```
┌─────────────────────────────────────────────────────┐
│  [midnight 배경 + 그레인]                              │
│  [대형 제품 이미지 배경 — 블러 + 다크 오버레이]           │
│                                                     │
│  · PRODUCTS                                         │
│                                                     │
│  가공제품                              ← Syne 64px   │
│                                                     │
│  방산 · 열교환기 · 산업기계               ← Body L     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- 대표 제품 이미지를 블러 처리한 배경
- 또는 솔리드 `midnight` + 글로우 블롭

### Section 2 — 카테고리 필터 (sticky)

```
┌─────────────────────────────────────────────────────┐
│                                                     │
│  [ 전체 ]   [ 방산 ]   [ 열교환기 ]   [ 기타 산업군 ]   │
│     ●                                               │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- 스크롤 시 상단 고정 (sticky)
- 활성 탭: `cyan-400` 하단 dot 또는 밑줄 + 텍스트 `gray-950`
- 비활성: `gray-400`
- 탭 전환 시 밑줄/dot 슬라이드 애니메이션

### Section 3 — 갤러리 (마소닉 그리드)

```
┌─────────────────────────────────────────────────────┐
│  [white 배경]                                        │
│                                                     │
│  ┌──────────┐  ┌──────┐  ┌──────────┐             │
│  │          │  │      │  │          │             │
│  │  이미지   │  │이미지 │  │  이미지   │             │
│  │  (세로형) │  │      │  │  (가로형) │             │
│  │          │  ├──────┤  │          │             │
│  │          │  │      │  └──────────┘             │
│  │          │  │이미지 │  ┌──────────┐             │
│  └──────────┘  │      │  │          │             │
│  ┌──────────┐  │      │  │  이미지   │             │
│  │  이미지   │  └──────┘  │          │             │
│  └──────────┘             └──────────┘             │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- 마소닉 (masonry) 레이아웃 — 이미지 원본 비율 유지
- 3열 (PC) / 2열 (태블릿) / 1열 (모바일)
- gap: 8px (빈틈 없는 밀도감)
- 호버: 이미지 scale(1.03) + 다크 오버레이(40%) + 카테고리 라벨 fade-in
- 클릭: 라이트박스 진입
- 필터 전환: Framer Motion `layout` + `AnimatePresence` (아이템 재배치 애니메이션)

## 라이트박스

```
┌─────────────────────────────────────────────────────┐
│  [backdrop: midnight/90 + backdrop-blur-xl]          │
│                                                     │
│                                                     │
│   ←  ┌───────────────────────────────────┐  →      │
│      │                                   │         │
│      │         원본 이미지                  │         │
│      │                                   │         │
│      │                                   │         │
│      └───────────────────────────────────┘         │
│                                                     │
│                    3 / 12                ← 인덱스    │
│                     ✕                   ← 닫기      │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- 진입: 클릭한 이미지 위치에서 확대 (shared layout animation)
- 배경: `midnight/90` + `backdrop-blur-xl`
- 좌우 네비: 화살표 키 + 스와이프 + 사이드 클릭 영역
- 하단: 현재 인덱스 / 총 개수 (Geist Mono)
- 닫기: ESC, 배경 클릭, X 버튼
- 이미지 전환: slide + fade

## 모바일 레이아웃 (< 768px)

### 갤러리 모바일

- 마소닉 3열 → 1열 세로 배치
- 이미지: 풀너비, 최대 높이 300px, `object-fit: cover`
- gap: 8px 유지
- 필터 탭: 좌우 스크롤 가능 (overflow-x: auto)

### 라이트박스 모바일

- 풀스크린
- 좌우 네비: 스와이프 (터치)
- 하단: 인덱스 + 닫기 버튼
- 상단 여백 축소

## 모션

| 요소 | 기법 | 트리거 |
|------|------|--------|
| 갤러리 아이템 | stagger fade-in + y(30→0) | scroll enter |
| 호버 오버레이 | opacity 0→0.4 + 텍스트 y(10→0) | hover |
| 필터 전환 | layout animation + AnimatePresence | tab click |
| 라이트박스 진입 | shared layout → scale-up | click |
| 라이트박스 이미지 전환 | slide-x + opacity | nav click |
| 필터 탭 인디케이터 | x-position 슬라이드 | tab click |

## 상태 디자인

| 상태 | 처리 |
|------|------|
| 이미지 로딩 중 | skeleton + blur-up (저해상도 20px blur → 원본 fade-in 0.5s) |
| 이미지 로드 실패 | `smoke` 배경 + 깨진 이미지 아이콘 (Lucide `ImageOff`, `gray-500`) |
| 카테고리 0개 | 중앙 정렬: 아이콘 (Lucide `PackageOpen`) + "등록된 제품이 없습니다" 텍스트 (`gray-500`) |
| lazy loading | `loading="lazy"` + IntersectionObserver. 뷰포트 200px 전 로드 시작 |
