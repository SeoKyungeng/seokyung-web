- 타이포: Syne **58-64px, weight 400, letter-spacing -0.04em**, 라인별 clip-path reveal 애니메이션 (1.2s stagger)
- 영상 하단: **diagonal-cut clip-path** (금속 절단 느낌)
- 스크롤 시: 영상 scale(1→1.1) + 텍스트 opacity fade-out (scrub)
- CTA: primary-400 배경 + 아웃라인 secondary
- 하단: 스크롤 인디케이터 (얇은 라인 + bounce)
- 배경에 은은한 블루 글로우 블롭 (다크 포인트 섹션)

## 모바일 레이아웃 (< 768px)

### 히어로 모바일

```
┌──────────────────────┐
│ [poster 정지 이미지]   │  ← 영상 미로드
│ [다크 오버레이]        │
│                      │
│ PRECISION            │  ← Syne 36-42px, weight 400
│ MACHINING            │
│ EXCELLENCE           │
│                      │
│ CNC·MCT 정밀 가공의    │
│ 선두주자              │  ← Body 16px
│                      │
│ [ 문의하기 → ]        │  ← 풀너비 CTA
│                      │
│ ↓                    │
└──────────────────────┘
```

- 영상 → poster 정지 이미지만 표시 (`<source media="(min-width: 768px)">`)
- Display 58-64px → 36-42px (weight 400)
- CTA 2개 → 1개 (문의하기만), 풀너비
- 패럴랙스 비활성화

### 벤토 그리드 모바일

```
┌──────────────────────┐
│ Since 2005           │  ← 풀너비 카드
```

- 카드 너비: `85vw`
- 진행 바 → dot 인디케이터로 전환

## 영상 상태 & LCP 전략

### 영상 로딩 상태

| 상태 | 처리 |
|------|------|
| 로딩 중 | poster 이미지 표시 (WebP, 200KB 이하) |
| 로드 성공 | poster → 영상 cross-fade (0.5s) |
| 로드 실패 | poster 이미지 유지 (정지 상태) |
| 모바일 | 영상 미로드. poster 이미지만 표시 |
| 저전력 모드 | 자동재생 차단 → poster 유지 |

### LCP 최적화

| 항목 | 스펙 |
|------|------|
| LCP 요소 | poster 이미지 (영상이 아님) |
| poster 포맷 | WebP, 200KB 이하 |
| poster preload | `<link rel="preload" as="image">` |
| 영상 포맷 | WebM 우선 + MP4 폴백 |
| 영상 최대 용량 | 3MB 이하 |
| 영상 preload | `preload="metadata"` (PC만) |
| 자동재생 | `autoplay muted playsinline loop` |
