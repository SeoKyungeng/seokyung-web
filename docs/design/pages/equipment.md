# 설비현황 페이지 구성

> 정보 중심 — 스펙 테이블, 데이터 강조, 수평 스크롤 쇼케이스

---

## 레이아웃

### Section 1 — 페이지 헤더 (70vh)

```
┌─────────────────────────────────────────────────────┐
│  [midnight 배경 + 그레인]                              │
│                                                     │
│  · EQUIPMENT                                        │
│                                                     │
│  설비현황                              ← Syne 64px   │
│                                                     │
│  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐          │
│  │ 14+  │  │ CNC  │  │ MCT  │  │범용선반│          │
│  │총 설비│  │ X대  │  │ X대  │  │ X대  │ ← 카운터  │
│  └──────┘  └──────┘  └──────┘  └──────┘          │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- 페이지 헤더에 설비 총괄 카운터 통합 (별도 섹션 불필요)
- 숫자: Geist Mono, 카운터 롤링
- 카드: `steel` 보더, 투명 배경

### Section 2 — CNC 설비 쇼케이스

```
┌─────────────────────────────────────────────────────┐
│  [white 배경]                                        │
│                                                     │
│  · CNC MACHINES                                     │
│                                                     │
│  ┌────────────────────────────────────────────┐     │
│  │                          │                 │     │
│  │   [장비 사진]              │  모델명          │     │
│  │   대형, 7:5 비율           │  ─────────────  │     │
│  │                          │  제조사   XXX    │     │
│  │                          │  수량     X대    │     │
│  │                          │  가공범위  XXXmm  │     │
│  │                          │  최대회전  Xrpm  │     │
│  │                          │  위치정밀  ±Xmm  │     │
│  │                          │                 │     │
│  └────────────────────────────────────────────┘     │
│                                                     │
│  ┌────────────────────────────────────────────┐     │
│  │                 │                          │     │
│  │  모델명          │   [장비 사진]              │     │
│  │  ─────────────  │   대형, 7:5 비율           │     │
│  │  제조사   XXX    │                          │     │
│  │  수량     X대    │                          │ ← 좌우 교차
│  │  ...            │                          │     │
│  └────────────────────────────────────────────┘     │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- 비대칭 2컬럼 (5:7) — 장비별 **좌우 교차 배치** (zigzag)
- 사진: 대형, 호버 시 미세 줌
- 스펙: key-value 형태, 라벨은 `gray-400` Caption, 값은 `gray-950` + Geist Mono
- 구분선: 1px `steel` 라인
- 스크롤 진입: 사진 slide-in (좌 또는 우) + 스펙 fade-in (stagger)

## 스펙 데이터 디자인

```
┌─────────────────────────────────┐
│  DOOSAN PUMA 400               │ ← H3, Syne
│                                │
│  제조사        Doosan           │ ← label: gray-400, value: Geist Mono
│  ─────────────────────────     │ ← 1px steel
│  수량          3대              │
│  ─────────────────────────     │
│  가공범위       Ø650 × 1,000mm  │
│  ─────────────────────────     │
│  최대회전수     3,000 rpm       │
│  ─────────────────────────     │
│  위치정밀도     ±0.005mm        │
│                                │
└─────────────────────────────────┘
```

- key: `gray-400`, Caption 크기, uppercase 가능
- value: `gray-950`, Geist Mono, Body 크기
- 행 구분: 1px `smoke` 라인 (라이트 배경) 또는 `steel` (다크 배경)

## 모바일 레이아웃 (< 768px)

### 장비 카드 모바일

```
┌──────────────────────┐
│                      │
│  ┌──────────────────┐│
│  │  [장비 사진]       ││  ← 풀너비
│  └──────────────────┘│
│                      │
│  DOOSAN PUMA 400     │  ← H3
│  ──────────────────  │
│  제조사     Doosan    │
│  ──────────────────  │
│  수량       3대       │
│  ──────────────────  │
│  가공범위   ...       │
│  ──────────────────  │
│  ...                 │
│                      │
└──────────────────────┘
```

- zigzag 좌우 교차 → 모두 세로 배치 (사진 상단, 스펙 하단)
- 사진: 풀너비, 비율 유지
- 스펙 테이블: 사진 아래

### 페이지 헤더 카운터 모바일

```
┌──────────────────────┐
│  설비현황             │  ← Syne 32px
│                      │
│  ┌─────┬─────┬─────┬─────┐│
│  │14+  │CNC  │MCT  │범용 ││  ← 4열 균등
│  │총설비│X대  │X대  │X대  ││
│  └─────┴─────┴─────┴─────┘│
└──────────────────────┘
```

- 카운터 카드: 4열 균등 배치 (모바일에서도 가로 유지, 또는 2×2 그리드)

## 모션

| 요소 | 기법 | 트리거 |
|------|------|--------|
| 헤더 카운터 | 0→N 롤링 | 페이지 로드 |
| 장비 사진 (홀수) | slide-in 좌→우 | scroll enter |
| 장비 사진 (짝수) | slide-in 우→좌 | scroll enter |
| 스펙 행 | stagger fade-in (위→아래) | scroll enter |
| 섹션 라벨 | fade-in + 시안 dot 확대 | scroll enter |

## 상태 디자인

| 상태 | 처리 |
|------|------|
| 이미지 로딩 중 | skeleton (이미지 비율 유지, `smoke` 배경 + 펄스) |
| 이미지 로드 실패 | 장비 아이콘 플레이스홀더 (Lucide `Cog` 아이콘, `gray-500`) |
| 장비 추가 시 | 동일한 카드 구조로 반복. CNC/MCT 섹션 내 카드 수 제한 없음 |
