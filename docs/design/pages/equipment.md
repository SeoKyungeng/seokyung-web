# 설비현황 페이지 구성

> 카테고리 탭 필터 + 벤토 그리드 + 인라인 확장 — 설비 브라우징 최적화

---

## 레이아웃

### Section 1 — 페이지 헤더 (70vh)

```
┌─────────────────────────────────────────────────────┐
│  [midnight 배경 + GrainOverlay + GlowBlob ×2]        │
│                                                     │
│  · EQUIPMENT                                        │
│                                                     │
│  설비현황                              ← Syne 64px   │
│                                                     │
│  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐          │
│  │ 14+  │  │ CNC  │  │ MCT  │  │범용선반│          │
│  │총 설비│  │ X대  │  │ X대  │  │ X대  │ ← 카운터  │
│  └──────┘  └──────┘  └──────┘  └──────┘          │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- midnight 배경 + GrainOverlay + GlowBlob 2개 (헤더 깊이감)
- 숫자: Geist Mono, 0→N 롤링 카운터
- 카드: `steel` 보더, 투명 배경

### Section 2 — 설비 갤러리

#### 2-1. Sticky 탭 바

```
┌─────────────────────────────────────────────────────┐
│  [sticky, z-30, bg-white/90 backdrop-blur]          │
│                                                     │
│   [전체]  [CNC]  [MCT]  [범용선반]  [기타]           │
│      ●                                              │
│   (슬라이딩 dot 인디케이터 — primary-400)             │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- `position: sticky`, `top: 0`, `z-30`
- 배경: `bg-white/90 backdrop-blur`
- 활성 탭 아래 dot 인디케이터: Framer Motion `layoutId` 슬라이딩, `primary-400` 색상
- 모바일: 수평 스크롤(`overflow-x: auto`) + `scroll-snap`

#### 2-2. 벤토 그리드 (PC)

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  ┌───────────────────────┬───────────┐                 │
│  │                       │           │                 │
│  │  첫번째 카드 (대형)     │ 두번째    │                 │
│  │  [사진 aspect-4/3]     │ [사진]    │                 │
│  │  모델명                │ 모델명    │                 │
│  │  장비명 · 제조사 · 수량 │ 장비명    │                 │
│  │  주요 스펙 2~3개       │ 제조사    │                 │
│  │                       │           │                 │
│  ├───────────┬───────────┤───────────┤                 │
│  │ 세번째     │ 네번째     │ 다섯번째  │                 │
│  │ [사진]    │ [사진]     │ [사진]    │                 │
│  │ 모델명    │ 모델명     │ 모델명    │                 │
│  │ 장비명    │ 장비명     │ 장비명    │                 │
│  └───────────┴───────────┴───────────┘                 │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

- `grid-cols-3`, `gap-6`
- 첫 번째 카드: `col-span-2 row-span-2` (대형), 사진 `aspect-[4/3]`
- 나머지 카드: `col-span-1`, 사진 `aspect-[7/5]`
- 카드 배경: `rounded-lg`, `bg-smoke`
- 사진 없을 때: Lucide `Cog` placeholder

#### 2-3. 카드 구조 상세

```
┌─────────────────────────────────────┐
│  ┌─────────────────────────────────┐│
│  │  [사진 영역]                      ││  ← rounded-lg, bg-smoke, overflow-hidden
│  │  aspect-[7/5] (소형)              ││
│  │  aspect-[4/3] (대형)              ││
│  └─────────────────────────────────┘│
│                                     │
│  DOOSAN PUMA 400                    │  ← font-display text-lg semibold (모델명)
│  CNC 선반                            │  ← text-sm text-gray-500 (장비명)
│  Doosan  ·  3대                     │  ← text-xs text-gray-400 (제조사 · 수량)
│                                     │
│  [ ▼ 스펙 보기 ]                     │  ← 클릭 시 AnimatePresence 인라인 확장
│                                     │
│  ┄┄┄┄┄ (확장 시 스펙 영역) ┄┄┄┄┄    │
│  가공범위    Ø650 × 1,000mm          │  ← SpecRow
│  최대회전수  3,000 rpm               │
│  위치정밀도  ±0.005mm                │
│  ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄    │
└─────────────────────────────────────┘
```

- 호버: `translate-y(-4px)` + `border-primary-400` + `shadow-lg`
- 스펙 확장: 클릭 → `AnimatePresence` 인라인 높이 애니메이션
- 이미지 호버: `scale(1 → 1.03)`, `ease-out`, 0.3s

```
┌──────────────────────┐
```

```
│  │ [사진 풀너비]      ││  ← 단일 컬럼 (grid-cols-1), aspect-[7/5]
│  └──────────────────┘│
│                      │
│  DOOSAN PUMA 400     │  ← font-display text-lg semibold

│  Doosan · 3대        │  ← text-xs text-gray-400
│                      │

│  ──────────────────  │
│  가공범위  Ø650×1,000 │  ← 확장 시 표시
```

## 모션

| 요소 | 기법 | easing | duration | 트리거 |
|------|------|--------|----------|--------|
| 헤더 카운터 | 0→N 롤링 | power1.out | 2s | 페이지 로드 |
| 탭 인디케이터 | layoutId 슬라이딩 dot | spring(400, 30) | ~0.25s | 탭 클릭 |
| 필터 전환 | AnimatePresence scale(0.95→1) + opacity | spring(300, 28) | ~0.3s | 탭 클릭 |
| 카드 진입 | stagger scale(0.95→1) + opacity | spring(300, 28) | 0.4s (stagger 0.06s) | 뷰포트 진입 |
| 카드 호버 | translate-y(-4px) + border + shadow | ease-out | 0.25s | hover |
| 스펙 확장 | height auto + opacity (행별 stagger) | spring(300, 25) | 0.35s | 클릭 |
| 카드 이미지 호버 | scale(1→1.03) | ease-out | 0.3s | hover |

## 상태 디자인

| 상태 | 처리 |
|------|------|
| 이미지 로딩 중 | skeleton (이미지 비율 유지, `smoke` 배경 + 펄스) |
| 이미지 로드 실패 | 장비 아이콘 placeholder (Lucide `Cog`, `gray-300`) |
| 필터 결과 없음 | 현재 모든 카테고리에 최소 1개 장비 존재 — 빈 상태 UI 불필요 |
| 스펙 미제공 | 스펙 버튼 비활성 또는 숨김 처리 |
