- 스플릿 레이아웃 (6:4)
- 좌: 문의 폼 / 우: 회사 정보
- 모바일: 폼 → 회사정보 세로 배치

### 폼 디자인

| 요소 | 스타일 |
|------|--------|
| 라벨 | `gray-400`, Caption, uppercase |
| 인풋 | 하단 보더만 (1px `gray-200`). 포커스 시 `cyan-400` 전환 |
| 플로팅 라벨 | 입력 시 라벨이 위로 이동 + 축소 (float label 패턴) |
| textarea | 높이 120px, 리사이즈 가능 |
| 전송 버튼 | 풀너비, `cyan-400` 배경, `midnight` 텍스트 |

### 폼 Validation 규칙

| 필드 | 규칙 | 에러 메시지 |
|------|------|------------|
| 회사명 | 필수, 2-50자 | "회사명을 입력해주세요" |
| 담당자명 | 필수, 2-20자 | "담당자명을 입력해주세요" |
| 연락처 | 필수, 한국 전화번호 형식 (`010-XXXX-XXXX` 또는 `02-XXX-XXXX` 등) | "올바른 연락처를 입력해주세요" |
| 이메일 | 필수, 이메일 형식 | "올바른 이메일을 입력해주세요" |
| 문의내용 | 필수, 10-2000자 | "문의내용을 10자 이상 입력해주세요" |

- validation 시점: 필드 blur 시 개별 검증 + 전송 시 전체 검증
- 에러 표시: 필드 하단 보더 `red-400` + 하단 에러 메시지 (`red-400`, Caption)

### 스팸 방지

| 항목 | 스펙 |
|------|------|
| 방식 | reCAPTCHA v3 (인비저블) |
| 배치 | 전송 버튼 하단에 reCAPTCHA 배지 (Google 정책 준수) |
| 시각 처리 | 배지 크기 축소 불가 (Google 요구), `gray-500` 텍스트로 안내 문구: "이 사이트는 reCAPTCHA로 보호됩니다" |
| 실패 시 | 토스트 에러: "보안 검증에 실패했습니다. 다시 시도해주세요" |

### 회사 정보 디자인

| 요소 | 스타일 |
|------|--------|
| 라벨 | `gray-400`, Caption |
| 값 | `gray-950`, Body. 전화/팩스/이메일은 Geist Mono |
| 구분선 | 1px `smoke` |

```

│              [Naver/Kakao 지도]                      │
```

- 풀너비, 높이 400px (PC) / 300px (모바일)

### 지도 로딩 상태

| 상태 | 처리 |
|------|------|
| 로딩 중 | skeleton (지도 비율 유지, `smoke` 배경 + 펄스) |
| 로드 성공 | skeleton → 지도 fade-in |
| 로드 실패 | 주소 텍스트 + "지도에서 보기" 외부 링크 (Naver/Kakao 지도 URL) |

## 폼 상태

| 상태 | 처리 |
|------|------|
| 빈 필드 전송 | 해당 필드 보더 `red-400` + 하단 에러 메시지 |
| 전송 중 | 버튼 → 로딩 스피너 + "전송 중..." 텍스트 |
| 전송 성공 | 폼 영역 → 성공 메시지 fade-in ("문의가 접수되었습니다") |
| 전송 실패 | 에러 토스트 + 폼 영역에 인라인 안내: "전송에 실패했습니다. 다시 시도하거나 이메일(info@sk-eng...)로 직접 문의해주세요" + [ 다시 시도 ] 버튼 |

## 모션

| 요소 | 기법 | 트리거 |
|------|------|--------|
| 폼 필드 | stagger fade-in + y(20→0) | scroll enter |
| 플로팅 라벨 | translateY + scale 전환 | input focus |
| 전송 버튼 | 배경 그라디언트 시프트 | hover |

| 회사 정보 | fade-in (폼보다 0.2s delay) | scroll enter |
