## 1. 프로젝트 개요

본 문서는 (주)서경엔지니어링 홈페이지 제작 프로젝트의 요구사항을 정의합니다.

| 항목 | 내용 |
|------|------|
| **프로젝트명** | (주)서경엔지니어링 홈페이지 제작 |
| **목적** | 기업 소개, 설비/제품 홍보, 문의 접수 |
| **타겟 사용자** | B2B 바이어, 거래처 담당자, 일반 방문자 |
| **지원 언어** | 한국어, 영어 (다국어 지원) |
| **반응형** | PC / 모바일 대응 |
| **기술 스택** | Next.js + TypeScript + Tailwind CSS |
| **예상 페이지 수** | 6페이지 (홈, 회사소개, 설비현황, 가공제품, 지속가능경영, 문의) |

## 3. 페이지별 상세 요구사항

### 3-1. 홈 (Home)

| 항목 | 내용 |
|------|------|
| **목적** | 기업의 첫인상을 전달하고 주요 섹션으로 유도 |
| **구성 요소** | 히어로 배너 영상, 회사 핵심 소개 요약, 주요 설비/제품 하이라이트, 문의하기 CTA 버튼, 푸터 (주소/전화/카피라이트) |
| **특이사항** | 배너 영상 필요. AI 및 무료 소스를 활용하여 자체 제작 예정이며, 퀄리티 미달 시 전문가 외주 진행. 영상 시작 시 오버레이 문구 삽입: *"We are one of best CNC,MCT machining field"* |

### 3-2. 회사소개

| 항목 | 내용 |
|------|------|
| **목적** | 기업의 비전, 리더십, 조직 구조 소개 |
| **구성 요소** | CEO 인사말 (사진 + 텍스트), 조직도 (부서별 구조) |
| **클라이언트 제공물** | CEO 사진, 인사말 텍스트, 조직도 데이터 |
| **특이사항** | 연혁 포함 여부 확인 |

### 3-3. 설비현황

| 항목 | 내용 |
|------|------|
| **목적** | 보유 설비의 사양과 역량을 전달하여 신뢰도 확보 |
| **구성 요소** | CNC 섹션: 장비 사진 + 스펙 테이블 (모델명, 수량, 가공범위 등), MCT 섹션: 장비 사진 + 스펙 테이블 |
| **클라이언트 제공물** | 장비별 사진, 스펙 데이터 |
| **특이사항** | 2026년 내 추가 기기 입고 예정. 관리자 페이지 미구현으로 인해 추가 기기 등록은 요청 시 무상으로 진행 (유지보수 정책 참고) |

### 3-4. 가공제품

| 항목 | 내용 |
|------|------|
| **목적** | 주요 가공 분야별 제품 사진을 전시하여 기술력 어필 |
| **구성 요소** | 방산 / 열교환기 / 기타 산업군 각각 사진 갤러리 (설명 텍스트 없음, 사진 중심 구성) |
| **클라이언트 제공물** | 분야별 제품 사진 |
| **특이사항** | 제품 설명 텍스트 미사용. 상세 페이지 없음. 갤러리 클릭 시 이미지 라이트박스(확대 보기)로 처리 |

### 3-5. 지속가능경영

| 항목 | 내용 |
|------|------|
| **목적** | ESG 경영 방침 및 인증 현황 소개 |
| **구성 요소** | ESG 관련 텍스트, 인증서 사진 등 |
| **클라이언트 제공물** | ESG 콘텐츠 텍스트, 인증서 이미지 |
| **특이사항** | 콘텐츠 형태 확인 필요 |

### 3-6. 문의하기

| 항목 | 내용 |
|------|------|
| **목적** | 방문자가 직접 문의를 보낼 수 있는 창구 |
| **구성 요소** | 문의 폼 (회사명, 담당자명, 연락처, 이메일, 문의내용), 회사 정보 (주소, 전화, 팩스), 지도 (Naver or Kakao) |
| **기능** | 폼 전송 시 지정 이메일로 메일 발송 |
| **클라이언트 제공물** | 수신 이메일 주소, 회사 주소/전화/팩스 |
| **특이사항** | 파일 첨부 기능 필요 여부, 스팸 방지 처리 필요 |
