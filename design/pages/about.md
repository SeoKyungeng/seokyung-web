# 회사소개 페이지 구성

---

## 레이아웃

### Section 1 — 페이지 헤더 (70vh)

```
┌─────────────────────────────────────────────────────┐
│  [midnight 배경 + 그레인]                              │
│  [시안 글로우 블롭 — 우상단]                            │
│                                                     │
│                                                     │
│  · ABOUT US                          ← SectionLabel │
│                                                     │
│  회사소개                              ← Syne 64px   │
│                                                     │
│  정밀 가공의 기술력으로                                 │
│  산업의 미래를 만들어갑니다              ← Body L       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- 풀블리드 다크 배경
- 텍스트 라인별 reveal 애니메이션
- 우상단 은은한 시안 글로우

### Section 2 — CEO 인사말 (비대칭 레이아웃)

```
┌─────────────────────────────────────────────────────┐
│  [white 배경]                                        │
│                                                     │
│  ┌───────────────┐                                  │
│  │               │     · CEO MESSAGE                │
│  │  CEO 사진      │                                  │
│  │  (7:5 비율)    │     "인사말 텍스트 첫 줄을          │
│  │               │      대형 타이포로 강조"             │
│  │               │                                  │
│  │               │     나머지 인사말 본문 텍스트        │
│  │               │     ...                          │
│  │               │     ...                          │
│  │               │                                  │
│  │               │              — 대표이사 OOO       │
│  └───────────────┘                                  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- 비대칭 2컬럼 (5:7)
- CEO 사진: 좌측, 상단 정렬. 스크롤 시 미세 패럴랙스
- 인사말 첫 문장: H3 크기로 강조 (Syne 또는 Pretendard SemiBold)
- 이름/직함: 우측 정렬, 1px 상단 보더
- 모바일: 사진 풀너비 → 텍스트

### Section 3 — 조직도 (다크 섹션)

```
┌─────────────────────────────────────────────────────┐
│  [slate 배경 + 그레인]                                │
│                                                     │
│  · ORGANIZATION                                     │
│                                                     │
│  조직도                                              │
│                                                     │
│                 ┌──────────┐                        │
│                 │ 대표이사   │                        │
│                 └────┬─────┘                        │
│            ┌─────────┼─────────┐                    │
│       ┌────┴────┐ ┌──┴───┐ ┌──┴────┐              │
│       │ 부서 1   │ │부서 2 │ │부서 3  │              │
│       └─────────┘ └──────┘ └───────┘              │
│                                                     │
└─────────────────────────────────────────────────────┘
```

- 다크 배경으로 시각적 전환
- 노드: `steel` 보더 카드, 시안 연결선
- 연결선: SVG path, 스크롤 진입 시 draw 애니메이션
- 노드: 상→하 순차 fade-in (stagger)
- 모바일: 세로 리스트 형태로 변환

## 모션

| 요소 | 기법 | 트리거 |
|------|------|--------|
| 페이지 헤더 텍스트 | line reveal | 페이지 로드 |
| CEO 사진 | slide-in (좌→우) + 미세 패럴랙스 | scroll enter |
| 인사말 텍스트 | fade-in + y(30→0) | scroll enter |
| 조직도 연결선 | SVG stroke-dashoffset draw | scroll enter |
| 조직도 노드 | stagger fade-in (상→하) | scroll enter |
